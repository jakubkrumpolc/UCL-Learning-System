How to use this site

Tip 1

Read one section at a time

Each numbered section teaches one idea. The numbers match the slides in your deck, so you can switch between them.

Tip 2

Open “More detail”

Under each section, the full explanation from the lecture plus extra context. Use the button in the sidebar to open them all.

Tip 3

Light box = pattern, dark box = real SQL

DELETE FROM table [WHERE condition];

Purple means type it, orange means fill it in, grey brackets mark optional parts.

Tip 4

Learn the “Remember” lines

Every section ends with a memory hook. They are all collected in section 65 for revision.
