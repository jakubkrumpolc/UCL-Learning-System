Settings

How the portal looks, how Scribe connects to xAI, and where your recordings are saved.

The theme is kept in this browser. Everything else is saved in the .env file in the portal folder.

Start the portal’s server to change Scribe’s settings

Pages opened as files can switch the theme, but can’t reach your xAI key or the saving options.

Start the portal with start.py in the portal folder (double-click it, or run python3 start.py), then open 127.0.0.1:8000/settings.html.

Appearance

Changes every page of the portal straight away, in every open tab. It doesn’t need saving.

Theme
System follows your computer’s setting. The moon and sun button in the top bar switches between light and dark on any page.

xAI speech-to-text

Scribe sends what your microphone hears to xAI, which writes it down as it’s spoken. These settings are used by Scribe.

Paste your xAI API key to start transcribing with Scribe.

Used for Scribe’s spend estimate. Check the current streaming price on xAI’s pricing page. With a budget set, you’re asked to confirm before recording once you’ve reached it.

Saving recordings

Scribe can also save each recording as files in a folder on this computer. Turn it on or off for each recording with Save to folder on the Scribe page.

Files are written while you record, so stopping early keeps what was saved. Scribe’s own copy, for its Recordings list and search, is kept either way.

Each saved recording gets its own files here, named by date and title. The folder is created if it doesn’t exist.

Save

Compressed audio is recorded by the browser: WebM in Chrome, Edge and Firefox, M4A in Safari. WAV plays and seeks in every player.
