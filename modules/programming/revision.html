Every memory hook

All 79 memory hooks from the guide. Each number links back to its section.

Part 1 · Values

  • 1 · print() shows a value but doesn't keep it. To keep a value, give it a name.
  • 2 · = means “let this name refer to this value”, not “equals”. Read it right to left.
  • 3 · Letters, digits and underscores; never start with a digit; never a keyword; case matters.
  • 4 · Dynamic: the type travels with the value, not the name. Strong: Python never guesses how to mix types.
  • 5 · # talks to people; indentation talks to Python. Four spaces per level, always the same.
  • 6 · int is exact and unlimited; float is approximate; complex has a j.
  • 7 · Floats are close, not exact: compare them with a tolerance, never with ==.
  • 8 · A backslash makes the next character special (\n), or stops it being special (\'). r"…" turns that off.
  • 9 · Slices include the start and exclude the end: s[1:3] is two characters.
  • 10 · type() asks “what kind?”; id() asks “which one?”.
  • 11 · Python widens types for you (int → float); narrowing (float → int) and str ↔ number are your job.

Part 2 · Decide

  • 12 · Colon, then indent: everything indented under the if runs only when the condition is True.
  • 13 · == compares, = assigns. Join conditions with and, or, not.
  • 14 · One if, any number of elifs, at most one else, and only the first True branch runs.
  • 15 · A if condition else B picks a value in one line; keep nesting shallow.
  • 16 · input() gives text. Wrap it in int() or float() to get a number.
  • 17 · / always gives a float; // rounds down; % is what's left over.
  • 18 · x += 1 is short for x = x + 1. A string never equals a number.
  • 19 · and needs both, or needs either, not flips it.
  • 20 · Shifting left by n multiplies by 2ⁿ; shifting right by n divides by 2ⁿ (rounding down).
  • 21 · in asks “is it inside?”; is asks “is it the very same object?”.
  • 22 · Brackets first, then **, then * /, then + -. When in doubt, add brackets.

Part 3 · Repeat

  • 23 · for walks through things you already have; while keeps going until something changes.
  • 24 · The loop variable takes each item in turn; you don't count, Python does.
  • 25 · range(n) gives n numbers: 0 up to n − 1. The stop value is never included.
  • 26 · A while loop needs three things: a start value, a condition, and a change that moves towards False.
  • 27 · Loop on < or >, not !=, especially with floats, so you can't step over the stopping point.
  • 28 · break leaves the loop, continue skips to the next round, pass does nothing at all.
  • 29 · A loop's else means “no break happened”.
  • 30 · Inner loop runs completely for every single step of the outer one: the counts multiply.

Part 4 · Collect

  • 31 · List = shopping list, tuple = date of birth, set = guest list, dict = phone book.
  • 32 · Square brackets make a list and also read from it: items[0] is the first, items[len(items) - 1] the last.
  • 33 · [-1] is the last item. For nested lists, one pair of brackets per level, outermost first.
  • 34 · list.method() changes the list itself; len, min, max, sum are functions you pass the list to.
  • 35 · L.sort() changes L and gives back nothing; sorted(L) gives back a new list and leaves L alone.
  • 36 · Read a comprehension as “give me this for each item in that if it passes”.
  • 37 · Tuples are read-only lists. A one-item tuple needs a comma: (11,).
  • 38 · A set keeps one of each and forgets the order: perfect for removing duplicates and for “is it in?”.
  • 39 · A dictionary maps keys to values: d[key] reads, d[key] = value writes, del d[key] removes.

Part 5 · Define

  • 40 · s[a:b] is from position a up to, but not including, b; s[-1] is the last character.
  • 41 · find says −1 when it fails; index raises an error. Both are case-sensitive.
  • 42 · Immutable values are replaced, never changed: “changing” a string really makes a new one.
  • 43 · def only defines the function; nothing runs until you call it with brackets: name().
  • 44 · Required first, in order; defaults fill gaps; keywords let you name them in any order.
  • 45 · One star gathers a tuple of values; two stars gather a dictionary of name=value pairs.
  • 46 · print shows a value to the user; return hands it back to the code. Only returned values can be stored.
  • 47 · LEGB: Local, Enclosing, Global, Built-in. Inside out, first match wins.
  • 48 · Only functions make a new scope. if and loops don't, but their variables exist only if the block ran.

Part 6 · Handle

  • 49 · An unhandled exception ends the program on the spot. Handling it lets the program carry on.
  • 50 · Put only the risky lines in try; except is the plan B; the program continues after both.
  • 51 · Most specific except first, except Exception last, because the first match wins.
  • 52 · else = it worked; finally = no matter what.
  • 53 · Open with with, and the file closes itself.
  • 54 · w wipes, a adds, r reads. Add + to do both, b for bytes.
  • 55 · For line-by-line work, loop over the file: for line in f:. It's short, fast and uses little memory.
  • 56 · write needs your own \n; writelines doesn't add any; print(…, file=f) does it for you.
  • 57 · Text mode gives you strings; binary mode ('b') gives you bytes, numbers from 0 to 255.

Part 7 · Objects

  • 58 · Each generation hides more of the machine. Objects hide the details behind a name and a set of actions.
  • 59 · Class = blueprint, object = the house. Calling the class, House(), builds a new object.
  • 60 · self is “this object”. __init__ sets up each new object; self.x = … gives it an attribute.
  • 61 · Class variable: one copy shared by every object. Object variable (self.x): each object has its own.
  • 62 · self → instance method, cls + @classmethod → class method, neither + @staticmethod → static method.
  • 63 · One underscore says “don't touch”; two underscores hide the name. In Python privacy is a convention, not force.
  • 64 · class Child(Parent): inherits everything. If the child has its own __init__, call the parent's yourself.
  • 65 · Python looks for a method in the child first, then the parents in order: the closest definition wins.

Part 8 · Import

  • 66 · A module is just a .py file. import name (no .py) runs it once and gives you its contents as name.thing.
  • 67 · import m → write m.x; from m import x → write x; as renames; avoid *.
  • 68 · Python searches the program's own folder first: never name your files after standard modules.
  • 69 · __name__ is "__main__" only in the file you ran. Put code that should run only then under the guard.
  • 70 · Before writing it yourself, check the standard library: maths, randomness, dates and files are all there.
  • 71 · Package = folder with __init__.py; dots in an import follow the folder path.
  • 72 · Logging shows messages at the set level and above; the default level is WARNING, so debug and info stay hidden.
  • 73 · Call basicConfig once, before the first log message, to set the level, the file and the format.

Part 9 · Analyse

  • 74 · NumPy = fast arrays of numbers; pandas = labelled tables built on top of NumPy. Import them as np and pd.
  • 75 · An array is a grid of same-typed values packed side by side: less flexible than a list, far faster.
  • 76 · Shapes are tuples: (rows, columns). linspace takes a count; arange takes a step and excludes the end.
  • 77 · ndim counts the axes; shape gives the size of each. Index a table with [row][column].
  • 78 · A Series is an array with labels: one value per label, read with s['label'], or s[['a', 'b']] for several.
  • 79 · DataFrame = a table of Series sharing one index: columns by name, rows by label.
