How to use this module

Tip 1

Read one section at a time

Each numbered section teaches one idea, with the code and what it prints side by side.

Tip 2

Open “More detail”

Under each section: the finer points, common mistakes and links to related sections. The button in the sidebar opens them all.

Tip 3

Dark box = code, grey box = output

Purple-tinted boxes are patterns to fill in: orange words in them are placeholders, grey brackets mark optional parts.

Tip 4

Run it yourself

Type the examples into PyCharm or a notebook and change them. Predict the output first, then check.
