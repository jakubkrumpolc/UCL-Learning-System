Data science, NumPy and pandas

“The ability to take data — to be able to understand it, to process it, to extract value from it, to visualize it, to communicate it — that's going to be a hugely important skill in the next decades.”

Hal Varian, chief economist at Google, 2009

NumPy

Numerical Python: large multi-dimensional arrays and matrices, plus fast maths on them.

import numpy as np

pandas

From “panel data” and “Python data analysis”: labelled columns (Series) and tables (DataFrames), like a spreadsheet in Python.

import pandas as pd

Install

pip install numpy pandas

Neither comes with Python. Install them once from a terminal (in Jupyter: !pip install numpy).

Remember: NumPy = fast arrays of numbers; pandas = labelled tables built on top of NumPy. Import them as np and pd.

More detail

Both libraries are written in Python and C. The C parts do the heavy number crunching, which is why they're so much faster than loops over Python lists.

np and pd are conventions, not rules, but every tutorial and answer online uses them.

Source: Lecture 9, “Data science”, “NumPy”, “Pandas”.

NumPy arrays

import numpy as np

arrA = np.array([30, 40, 50])               # rank 1
print(arrA)

arrB = np.array([[10, 20, 30], [40, 50, 60]])  # rank 2
print(arrB)
[30 40 50]
[[10 20 30]
 [40 50 60]]

Lists versus arrays

Python listNumPy array
Itemsany mix of typesone type, all the same size
Memoryscattered objectsside by side
Speedslowermuch faster for maths
Flexibilityhighlower

Data types

np.int8 … np.int64

np.uint8 … np.uint64

np.float32, np.float64

np.complex64

np.bool_

Every array has a dtype (data type). Because all items share it, NumPy can pack them tightly and work on them quickly.

Remember: An array is a grid of same-typed values packed side by side: less flexible than a list, far faster.

More detail

Arrays print without commas: [30 40 50]. That's how to tell an array from a list in output.

The big win, not shown in the lecture, is vectorised maths: arrA * 2 gives [60 80 100] and arrA + arrA adds item by item, with no loop. On a list, * 2 would repeat the list instead.

“Rank” or “dimension” is the number of axes: a row of values is rank 1, a table is rank 2.

Source: Lecture 9, “NumPy”, “NumPy Datatypes”, “NumPy array data type”.

Creating arrays

CallMakesPrints
np.array([1, 2, 3])from a list (or tuple)[1 2 3]
np.zeros((2, 2))all zeros, given shape[[0. 0.] [0. 0.]]
np.ones((3, 2))all ones, 3 rows × 2 columns[[1. 1.] [1. 1.] [1. 1.]]
np.full((2, 2), 13)every item 13[[13 13] [13 13]]
np.eye(2)identity matrix[[1. 0.] [0. 1.]]
np.linspace(0, 2, 9)9 evenly spaced values from 0 to 2[0. 0.25 0.5 … 1.75 2.]
np.arange(2, 7)like range, as an array[2 3 4 5 6]
np.arange(2, 3, 0.1)float steps allowed[2. 2.1 2.2 … 2.9]
np.random.random((2, 3))random floats from 0 to 1different every time

Remember: Shapes are tuples: (rows, columns). linspace takes a count; arange takes a step and excludes the end.

More detail

zeros, ones and eye make floats by default, which is why they print as 0. and 1.; full keeps the type of the value you give it.

np.arange accepts a float step, unlike range, but rounding can make the number of items surprising. When you need an exact count of points, use linspace.

Source: Lecture 9, “Creating arrays”: conversion, NumPy functions, random.

Shape, indexing, and saving arrays

arrA = np.zeros((2, 2))
arrB = np.ones((3, 2))
print(arrA.ndim, arrB.ndim)     # number of axes
print(arrA.shape, arrB.shape)   # size along each axis
2 2
(2, 2) (3, 2)
arrA[0][1] = 12        # row 0, column 1
print(arrA)
[[ 0. 12.]
 [ 0.  0.]]

Save to a file and load it back

values_out = np.array([102, 754, 387])
np.savetxt('data.out', values_out, fmt='%d')
values_in = np.loadtxt('data.out', dtype=int)
print(values_in)
[102 754 387]

Remember: ndim counts the axes; shape gives the size of each. Index a table with [row][column].

More detail

NumPy also accepts arrA[0, 1] for the same element; it's the more common form and works with slices across both axes: arrB[:, 0] is the whole first column.

print(arrA[0]) prints the first row, [0. 0.].

savetxt writes one value per line by default; fmt='%d' writes them as whole numbers. loadtxt reads them back, and dtype=int makes them integers again.

Source: Lecture 9, “Dimension of an array”, “Shape of an array”, “Change an element”, “Saving NumPy arrays to a file”.

pandas Series: a labelled column

import pandas as pd

serieA = pd.Series([87, 34, 90, 7, 11, 6])
print(serieA)
0    87
1    34
2    90
3     7
4    11
5     6
dtype: int64
print(serieA.index)
print(serieA.values)
RangeIndex(start=0, stop=6, step=1)
[87 34 90  7 11  6]
capitals = ['Nigeria', 'Japan', 'Jordan', 'UK']
population = [211.4, 125.7, 10.27, 67.33]
serieB = pd.Series(population, index=capitals)

print(serieB['UK'])
print(serieB[['UK', 'Nigeria']])
67.33
UK          67.33
Nigeria    211.40
dtype: float64

How to see it

A Series is two arrays: the index (labels) and the values. Without labels you get 0, 1, 2…

Remember: A Series is an array with labels: one value per label, read with s['label'], or s[['a', 'b']] for several.

More detail

The left-hand column in the printout is the index, not part of the data. dtype: int64 tells you the type of the values.

Note the double brackets for several values: the inner brackets are a list of labels.

Source: Lecture 9, “Series”, “Getting the index and the values”, “Defining Series objects with individual indices”, “Accessing values”.

pandas DataFrame: a labelled table

my_data = [['Italy', 61, 0.83], ['Spain', 46, 0.63], ['Greece', 11, 0.15],
           ['France', 65, 0.88], ['Portugal', 10, 0.14]]

df = pd.DataFrame(my_data,
                  index=['IT', 'ES', 'GR', 'FR', 'PO'],
                  columns=['Country', 'Popu', 'Percent'])
print(df)
     Country  Popu  Percent
IT     Italy    61     0.83
ES     Spain    46     0.63
GR    Greece    11     0.15
FR    France    65     0.88
PO  Portugal    10     0.14

What you get

  • 2-dimensional and labelled: row labels (the index) and column names
  • Each column can have its own type: text, whole numbers, decimals
  • Each column is a Series
df['Popu']          # one column
df.loc['IT']        # one row by label
df['Popu'].mean()   # 38.6

Remember: DataFrame = a table of Series sharing one index: columns by name, rows by label.

More detail

pandas can load tables straight from files: pd.read_csv('data.csv') gives a DataFrame, which is far easier than parsing the file yourself with the tools from Part 6.

The lecture's useful links: tutorialspoint's NumPy and pandas tutorials, and LinkedIn Learning's “Python: Data Analysis”.

Source: Lecture 9, “DataFrame”, “Useful links”.
