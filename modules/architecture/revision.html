Three checks

  • 4210 = 1010102 = 2A16.
  • The byte 11111000 plus 00001111 is 00000111 with a carry. Unsigned, that is overflow (248+15). Signed, it is the correct −8+15 = 7.
  • −12.75 as an IEEE float is 0xC14C0000. 1.0 is 0x3F800000.

A normal float is (−1)S × 1.F × 2E−127. E = 0 and E = 255 are the specials.

Remember: Flip and add 1 to negate. Carry out means unsigned overflow. A wrong sign means signed overflow. Copy the sign when you widen.

More detail

The full derivations are in Part 2 and in the floating-point section of Part 4. If a check above fails when you redo it, go back to the worked column rather than to a new mnemonic.

MARS: code at 0x00400000, your .data at 0x10010000. Exit is li $v0, 10 then syscall. Print string is 4, read int is 5, print int is 1.

A frame that saves the return address:

addi $sp, $sp, -8
sw   $ra, 4($sp)
sw   $fp, 0($sp)
addi $fp, $sp, 4
# ... jal something ...
lw   $ra, 4($sp)
lw   $fp, 0($sp)
addi $sp, $sp, 8
jr   $ra

Remember: R is op-rs-rt-rd-shamt-funct. Loads sign-extend the offset. jal saves $ra. The stack grows down, and you restore $ra before you add $sp back.

More detail

The five addressing modes: immediate, register, base, PC-relative, pseudo-direct. addi, beq and lw are all I-type and use the first, the fourth and the third.

Parts 3 and 4 have the encodings written out bit by bit. Re-encode add $8, $1, $2 until the fields come out without looking.

Semaphorewait and signal on an integer. A queue lets wait sleep

Boot, in one breath

Firmware (BIOS from CMOS and an MBR, or UEFI from NVRAM and a GPT .efi loader) runs POST, loads a bootloader, and the bootloader loads the kernel. Then the kernel loads you.

Memory, in one breath: logical addresses, an MMU, pages and frames, a valid bit, a fault that restarts the instruction. FIFO can get worse with more frames. OPT needs the future (9 faults on the lecture string). LRU uses the past (12). The string’s FIFO count is 15.

Remember: An interrupt is the device. A trap is the program. The mode bit is the boundary. A process is a PCB. FIFO 15, OPT 9, LRU 12, on three frames.

More detail

If a definition on this card feels thin, it is a pointer back to Parts 5–8, not a second copy of them.

How to recompute one under pressure

  • Draw the Gantt chart before any subtraction. Waiting time is time in the ready queue, not time running.
  • FCFS and RR need only the chart. SJF needs a “who is ready, whose burst is shortest?” at every decision.
  • SRTF redecides at every arrival. The 6.5 comes from waits 9, 0, 15 and 2.
  • A disk total is the sum of absolute jumps. Write every jump. SSTF’s easy miss is leaving 67 for later; it is 2 cylinders from 65.

The charts themselves are drawn in Part 7 and Part 8. This table is the answer key for those drawings.

Remember: Draw the chart, then the average. The lecture’s headlines are FCFS 17, SJF 7 (or 5 with the printed arrival times), SRTF 6.5, priority 8.2, RR 17/3, disk FCFS 640.

More detail

Where a slide prints both arrival times and the average 7, the average matches “everyone is ready at time 0” and the arrivals match a different trace whose average is 5. Show which assumption you used. Both traces are in Part 7.

Source: Lectures 16 and 19, worked in Parts 7 and 8.

The rover: the rules, traced

What each command does to the charge

KeyEffectThen
C n+n (recharge)drain PDR
S n+2n (solar align)drain PDR
D n+2n (dock)drain PDR
T n−3n (traverse)drain PDR
Rcharge ← the operator’s IBC, not the default 5drain stays off for this second
Qquit

Inside one simulated second the command is applied first and the natural drain second. The telemetry line shows the charge after both. Clamp every result to 0 … MBC. The “capped” error is only when a command would have gone above MBC; landing exactly on MBC is a normal success. Going offline prints the offline error, including when the drain alone causes it.

While offline, drain is suspended and only R and Q are accepted. Anything else is rejected and does not change the charge. R restores the IBC the operator typed. n has to be a positive integer; bad input does not change the charge.

The sample, with PDR 2, MBC 20, IBC 8

At the promptWhat happensShown charge
t = 00:03, no command yet8 − 2×32
C 62+6 = 8, then drain 26
S 36+6 = 12, then drain 210
D 210+4 = 14, then drain 212
T 212−6 = 6, then drain 24
C 304+30 caps at 20, then drain 218
seven quiet seconds, to t = 00:1518 − 2×74
T 34−9 clamps to 0, offline, drain does not also apply0
Rback to IBC 8, drain resumes next second8

S and D use the same arithmetic and must still print different messages. The defaults, if the operator just presses Enter, are PDR 1, MBC 15, IBC 5.

The MIPS for this is yours to design: a loop, branches, arithmetic, and syscall for the prompts. Parts 3 and 4 are the instruction set that loop is written in. This table is the specification’s own sample, checked against the ordering rules, so you can diff your telemetry against it.

Remember: Apply the command, then the drain, then clamp to 0…MBC. Offline suspends the drain and accepts only R and Q. R restores the operator’s IBC.

More detail

The brief asks for those messages exactly, including “Error, maximum battery capacity reached! Capped to the Max.” and “Error, charge level equal to or less than 0. Rover is offline!” and “Rover is offline. Perform a reset (R) to continue.” Invalid input is “Invalid command. Use C n | S n | D n | T n | R | Q.” with the note that n should be positive.

A command that arrives in a second does not skip the drain, except while the rover is offline and except on the reset second, where the brief shows the charge sitting at IBC with the drain resuming afterwards. The C 30 line is the one to re-read: the cap happens before the drain, so the display is 18, not 20.

Every memory hook

One line from each section

#Remember
1Architecture is the instruction set the programmer sees. Organisation is one way of building it.
2The machines changed. The stored-program idea did not. MIPS is the clean place to learn it.
3One addition is the same idea at every level, from i = i + 1 down to a word of bits.
4Instructions and data share one memory. The program counter says which word is fetched next.
5A mailbox holds one 3-digit word: a number, or an opcode plus an address.
6Assembly is a 1-to-1 renaming of machine code. ADD 99 and 199 are the same instruction.
7A branch writes a new address into the program counter. That is what makes the machine more than a calculator.
8Real hardware is the Little Man’s room: a processor, a memory of instructions and data, and buses instead of a person. The numbers are binary.
9A number is digits times powers of the base. Multiply by the base by writing a 0 on the right.
10Four bits are one hex digit. Group from the right, and pad the left with zeros if you must.
11In memory, kilo usually means 1024. On a wire, kilo means 1000. The formal name for 1024 bytes is a kibibyte.
12Each column: add the digits and the carry, divide by the base, write the remainder, carry the quotient.
13To negate: flip every bit, then add 1. Subtraction is adding that negation. Zero is all zeros, once.
14n bits hold 2ⁿ patterns. Unsigned runs from 0 to 2ⁿ−1. Signed runs from −2ⁿ⁻¹ to 2ⁿ⁻¹−1. The bits do not say which reading you meant.
15A carry out of the top bit means unsigned overflow. Signed overflow is two numbers of the same sign adding to the opposite sign.
16Little-endian stores the low byte at the low address. Widen a signed value by copying the sign bit. Widen an unsigned value with zeros.
17MIPS arithmetic happens in registers. Only load and store touch memory, so adding two memory words takes four instructions. $0 is always 0.
18R-type is op, rs, rt, rd, shamt, funct. op is 0 and funct picks add (0x20) or sub (0x22). The destination is written first in assembly and fourth in the word.
19add and addu compute the same sum. add traps on signed overflow; addu does not. and, or, xor and nor act on each bit on its own.
20I-type is op, rs, rt, and 16 bits. lw and sw use rt as the data register and rs plus a sign-extended offset as the address. 0x8000 extends to 0xFFFF8000.
21A branch offset counts instructions from the next instruction. lui then ori plants any 32-bit constant. addiu sign-extends its immediate; the “u” only switches off the overflow trap.
22The format is how the bits are packed. The addressing mode is how the operand is found. addi, beq and lw are all I-type and use three different modes.
23A logical left shift by k multiplies by 2ᵏ and brings in zeros. An arithmetic right shift copies the sign. A mask and a shift pull one field out of a machine word.
24slt writes 1 or 0. A branch then tests that against zero. |A−B| is subtract, branch if it is already positive, otherwise subtract the other way.
25.data and .text choose the segment. A label is a name for an address. In MARS, code starts at 0x00400000 and your words start at 0x10010000.
26$a0–$a3 carry arguments in. $v0–$v1 carry results out. $t registers are scratch. $s registers survive a call.
27An if is a branch around one arm and a jump around the other. A loop tests at the top, and jumps back from the bottom.
28jal writes the next address into $ra and jumps. jr $ra returns. A nested jal overwrites $ra unless you have saved it.
29The caller may trust $s registers and must assume $t registers die. A procedure that uses an $s register, or that calls onward, saves and restores what it will overwrite.
30The stack grows down. Subtract from $sp, store $ra and $fp, do the work, load them back, add the same amount to $sp, then jr $ra.
31Put a service number in $v0, arguments in the documented registers, and execute syscall. 4 prints a string, 5 reads an int, 1 prints an int, 10 exits.
32A C string is ASCII bytes ending in 0. A fixed-point binary point is a convention, not a stored bit. After a fixed-point multiply, shift right by the number of fraction bits.
33A normal float is (−1)ˢ × 1.F × 2ᴱ⁻¹²⁷. E = 0 and E = 255 are reserved: zero, denormals, infinity, NaN. −12.75 is 0xC14C0000.
34Firmware runs first, from ROM or flash. It loads an operating system into RAM. The operating system loads your program.
35BIOS reads CMOS, initialises the hardware, runs POST, finds a Master Boot Record, and jumps to that bootloader.
36UEFI is firmware in flash. It boots large GPT disks, can check the OS before running it, and starts a .efi loader rather than a 512-byte MBR.
37BIOS and UEFI both end by jumping to a bootloader in RAM. They differ in where settings live, how the disk is partitioned, and whether the operating system is checked first.
38The kernel is the program that is always running. It allocates hardware and stops programs damaging each other. Everything else is a system program or an application.
39Polling keeps asking. An interrupt is the device ringing, and the vector says which routine answers. A trap is an interrupt caused by the program: a fault, or a request for a service.
40Closer to the CPU means faster, smaller and more expensive. A cache holds a temporary copy of what is in use. Main memory forgets when the power goes; a disk or SSD does not.
41Symmetric multiprocessing lets every CPU run any task. Asymmetric multiprocessing keeps a boss processor. A cluster is separate computers sharing the work.
42A mode bit separates user code from kernel code. Privileged instructions run only in kernel mode. A system call flips the bit; the return flips it back.
43A process is a running program. The kernel schedules processes, tracks memory, presents files, and hides each device behind a driver.
44Programs call an API, and the API makes the system call. The groups are processes, files, devices, information, communication and protection.
45Policy is what should happen. Mechanism is how it happens. Keep them apart so a new decision does not mean a new machine.
46A process is a running program: code, program counter, registers, stack, data and heap. The PCB is the record that lets the CPU leave and come back. States are new, ready, running, waiting, terminated.
47A context switch saves one PCB and loads another, and does no useful work while it does. The short-term scheduler picks the next process every few milliseconds. The long-term scheduler decides who is allowed into memory.
48Cooperating processes share memory or pass messages. An ordinary pipe is one-way between parent and child. A socket is an IP address plus a port. 127.0.0.1 is this machine.
49Only one process may be in the critical section. A correct protocol has mutual exclusion, progress, and bounded waiting.
50A mutex is a lock: acquire waits, release opens it. A spinlock waits by looping. A semaphore is an integer changed only by wait and signal; with a queue, wait sleeps instead of spinning.
51FCFS can trap a short job behind a long one: the convoy effect. SJF gives the shortest average wait if you know the next burst. Estimate that burst with τₙ₊₁ = α tₙ + (1−α) τₙ.
52Priority scheduling can starve a low-priority job; ageing raises it as it waits. Round robin gives each job a quantum q, and nobody waits longer than (n−1)q. A huge q is FCFS.
53A multilevel queue keeps a job in one queue. A feedback queue lets it fall: in the lecture, RR for 8 ms, then RR for 16 ms, then FCFS.
54The CPU generates logical addresses. The MMU turns them into physical ones, in the simple scheme by adding a relocation register. Binding at run time is what makes that possible.
55First fit takes the first hole that fits. Best fit takes the smallest. Worst fit takes the largest. External fragmentation is free memory in the wrong shape. Internal fragmentation is waste inside an allocation.
56A segment address is <segment, offset> and matches the program. A page address is <page, offset> into equal frames. Segmentation fragments the gaps. Paging fragments the last frame.
57Virtual memory runs a process with only some pages resident. A valid bit says the page is in RAM. A page fault loads it and restarts the instruction.
58FIFO evicts the oldest page and can fault more with more frames: Belady’s anomaly. OPT evicts the page used furthest ahead. LRU evicts the page unused for longest. On the lecture’s string, the counts are 15, 9 and 12.
59A disk access is seek, then rotational latency, then transfer. An SSD has no arm and no platter, so it has neither of the first two. Seek time grows with how far the arm moves.
60FCFS serves the queue in order (640 on the lecture’s queue). SSTF takes the closest request (236) and can starve. SCAN sweeps like an elevator. C-SCAN returns without serving, so the wait is fairer. LOOK turns at the last request, not at the rim.
61Flip and add 1 to negate. Carry out means unsigned overflow. A wrong sign means signed overflow. Copy the sign when you widen.
62R is op-rs-rt-rd-shamt-funct. Loads sign-extend the offset. jal saves $ra. The stack grows down, and you restore $ra before you add $sp back.
63An interrupt is the device. A trap is the program. The mode bit is the boundary. A process is a PCB. FIFO 15, OPT 9, LRU 12, on three frames.
64Draw the chart, then the average. The lecture’s headlines are FCFS 17, SJF 7 (or 5 with the printed arrival times), SRTF 6.5, priority 8.2, RR 17/3, disk FCFS 640.
65Apply the command, then the drain, then clamp to 0…MBC. Offline suspends the drain and accepts only R and Q. R restores the operator’s IBC.
