COMP0068 · Computer Architecture & Operating Systems

From bits
to processes

The lecture decks rebuilt into one path: how a machine represents numbers, how MIPS runs an instruction, how C and Python constructs become assembly, then the operating system that boots, schedules and pages. Every worked example uses the lecture’s own numbers.

How to use this module

Tip 1

Convert it by hand

Cover the answer, turn the number into the other base, then check. The same habit works for a MIPS instruction word.

Tip 2

Single-step in MARS

The assembly on these pages is the lecture’s own. Load it in MARS, step one instruction, and watch the register it names.

Tip 3

Open “More detail”

Under each section: the extra cases, the bounds, and which lecture it comes from. The button in the sidebar opens them all.

Tip 4

Learn the “Remember” lines

Every section ends with one. They are collected on the revision page.
