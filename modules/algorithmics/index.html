How to use this module

Tip 1

Trace it by hand

Every algorithm comes with a worked example. Cover the trace, run the pseudocode on paper, then check.

Tip 2

Open “More detail”

Under each section: the finer points from the notes and the reasoning behind each step. The button in the sidebar opens them all.

Tip 3

Light box = pseudocode

Purple words are keywords. Arrays are numbered from 1, as in the notes; code them in Python (which counts from 0) to see them run.

Tip 4

Learn the “Remember” lines

Every section ends with a memory hook. They're all collected on the revision page.
